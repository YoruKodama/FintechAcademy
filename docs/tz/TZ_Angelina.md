## Задачи (по порядку важности)

### А5. Оценщик баллов (до 27 окт) — первой
- `score(findings, llm_answer, text_answers) -> Result`. Часть баллов считается правилами из замечаний, часть берётся у модели. `temperature=0`.
- Готово, когда: одинаковый ввод даёт одинаковый итог (3 прогона); итог от 0 до 100, критерии от 0 до 25; тесты на пустое решение, решение без замечаний, сломанный ответ модели.

### А8. Цепочка submit (до 27 окт) — новое
- Файл `backend/app/pipeline.py`: `run_pipeline(code: str, answers: list[str], findings: list[Finding]) -> Result`.
- Порядок: анонимизировать код и ответы, вызвать модель, вызвать `score`. Анализ кода (`findings`) делает Юра до вызова.
- API Юры уже подключает вашу функцию автоматически, как только файл `app/pipeline.py` появится, до этого работает заглушка.
- Ошибка модели не роняет API: возвращается понятный результат или исключение с русским сообщением.
- Готово, когда: тесты на `StubClient`; персональные данные не попадают в запрос к модели (тест).
