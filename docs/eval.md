# Сравнение с эталоном

Скрипт `scripts/eval.py` прогоняет все решения из `testdata/solutions/` через систему
(обезличивание, модель, оценщик) и сравнивает итоговый балл с эталоном Андрея.

## Как запустить

```bash
LLM_PROVIDER=ollama python scripts/eval.py
```

Полезные ключи:

- `--no-write` — только напечатать таблицу, не менять этот файл;
- `--expected expected.json` — эталоны из отдельного файла `{"имя_решения": 78}`;
- `--solutions DIR` — другая папка с решениями.

При `LLM_PROVIDER=stub` баллы заглушки не отражают модель, поэтому скрипт ничего не записывает
в этот файл (разрешить можно ключом `--allow-stub`, например для проверки самого скрипта).

## Формат testdata/solutions/

Формат нужно сверить с Андреем.

- `<имя>.py` — решение;
- `<имя>.json` (необязательно) — `{"task": "...", "questions": [...], "answers": [...], "findings": [...], "expected": 78}`;
  `findings` — замечания анализатора, если их не задать, берутся из `app.analysis.analyze`, когда модуль есть.

## Условия прогона

31.10.2026, модель `qwen2.5:7b` в Ollama на CPU без видеокарты, тайм-аут запроса 300 с (в самом
проекте он 60 с, на этом компьютере модель на него не укладывается), 20 решений из
`testdata/solutions/`, эталон Андрея. Один прогон: повторные прогоны могут чуть отличаться.

## Выводы

1. Хорошие и отличные решения оцениваются близко к эталону (разница от 0 до 11 баллов), например
   `s1_01_excellent` совпало точно (97).
2. Самые плохие решения система завышает: опасные (`eval`, `os.system`) и сломанные получают около 20
   при эталоне 2-6. Правила обнуляют безопасность (проверено на `s1_05_dangerous`), но они только
   ограничивают баллы сверху, а оценки за правильность и качество кода у такого решения ставит
   модель `qwen2.5:7b`, и она их завышает.
3. `s2_03_no_luhn` занижено на 26 (система 25, эталон 51): анализатор по `ast` не видит, что нет
   алгоритма Луна, оценку здесь формирует модель; причину по её ответу мы не разбирали.
   Ещё три решения с лёгкими замечаниями (`s2_06`, `s2_07`, `s3_03`) завышены на 13-16.

Средняя ошибка 9,2 балла на 20 решениях: это итог для слайда «метрики»; доля решений с разницей
не более 10 баллов: 12 из 20 (60 %).
