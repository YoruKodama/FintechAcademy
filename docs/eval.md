# Сравнение с эталоном

Скрипт `scripts/eval.py` прогоняет все решения из `testdata/solutions/` через систему
(обезличивание, модель, оценщик) и сравнивает итоговый балл с эталоном Андрея.

## Как запустить

```bash
LLM_PROVIDER=ollama python scripts/eval.py
```

Полезные ключи:

- `--no-write` — только напечатать таблицу, не менять этот файл;
- `--expected expected.json` — эталоны из отдельного файла `{"имя_решения": 78}`;
- `--solutions DIR` — другая папка с решениями.

При `LLM_PROVIDER=stub` баллы заглушки не отражают модель, поэтому скрипт ничего не записывает
в этот файл (разрешить можно ключом `--allow-stub`, например для проверки самого скрипта).

## Формат testdata/solutions/

Формат нужно сверить с Андреем.

- `<имя>.py` — решение;
- `<имя>.json` (необязательно) — `{"task": "...", "questions": [...], "answers": [...], "findings": [...], "expected": 78}`;
  `findings` — замечания анализатора, если их не задать, берутся из `app.analysis.analyze`, когда модуль есть.
