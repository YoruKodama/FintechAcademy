# Видео-демо (Т8): сценарий на 2–3 минуты

Правило ТЗ: **показываем только то, что реально работает.** Запуск кода в контейнере в демо
выключен — не показываем и не обещаем. Если запись без Ollama, говорим «модель-заглушка».

## Подготовка (5 минут)

1. Система запущена (демо-ссылка Юры или локально `docker compose up --build`), желательно с
   `LLM_PROVIDER=ollama`, чтобы разбор был настоящим.
2. Открыть заранее в блокноте: `testdata/solutions/s1_03_float.py` (решение с ошибками —
   балл и замечания нагляднее) и ответы из `testdata/solutions/s1_03_float.json`.
3. Браузер: одна вкладка, масштаб 110–125 %, закрыть закладки и уведомления.
4. Запись: Windows — `Win + Alt + R` (Xbox Game Bar) или OBS; разрешение 1920×1080.
5. Сделать один пробный прогон: первое прохождение может идти дольше (модель прогревается).

## Сценарий

| Время | Что на экране | Что говорим (или субтитр) |
|---|---|---|
| 0:00–0:15 | Главная, три задачи | «Это тренажёр технических собеседований для сотрудников банка. Кандидат выбирает задачу на Python из банковской области.» |
| 0:15–0:35 | Открыть «Расчёт комиссии за перевод», прокрутить условие и вопросы | «У задачи есть условие, шаблон кода и три вопроса — как на настоящем собеседовании.» |
| 0:35–1:05 | Вставить код `s1_03_float.py` в редактор, вписать ответы | «Пишем решение в редакторе и отвечаем на вопросы. Здесь специально решение с типичной ошибкой — деньги во float.» |
| 1:05–1:20 | «Отправить» → «Проверяем решение…» | «Система обезличивает текст, анализирует код по восьми правилам и передаёт его локальной модели. Персональные данные в модель не уходят.» |
| 1:20–2:05 | Экран результата: балл, 4 критерия, разбор, замечания со строками | «Итог — балл от 0 до 100 и четыре критерия по 25. Модель пишет разбор по-русски, а анализатор показывает замечания с номерами строк: здесь — float для денег.» |
| 2:05–2:35 | «Панель руководителя», фильтр по сценарию, «Открыть» | «Руководитель видит все прохождения, баллы и может открыть любой разбор.» |
| 2:35–2:50 | Вернуться на главную | «Модель работает локально в Ollama и заменяется на российскую одной настройкой. Спасибо!» |

Если модель — заглушка, на 1:05 сказать: «В этой записи модель-заглушка; с Ollama разбор
формируется настоящей моделью.»
