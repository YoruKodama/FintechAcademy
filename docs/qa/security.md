# Проверка безопасности запуска кода (Т6)

Статус: **ожидает реализации песочницы** (`backend/app/analysis` пока пустой).
Набор атак готов: `testdata/security/`, прогон: `tests/security/run_security_suite.py`.

## Требования (ТЗ и жюри)

- чужой код запускается **только в изолированном контейнере**;
- лимиты: время `SANDBOX_TIMEOUT_SEC` (5 с), память `SANDBOX_MEMORY_MB` (128 МБ);
- ожидаемые настройки контейнера: без сети (`network_mode: none`), файловая система только
  для чтения, непривилегированный пользователь, `pids_limit`, `cpus`, без секретов в окружении,
  без монтирования исходников и `.env`.

## Уже известно до прогона

- `anonymize()` работает квадратичное время на длинной строке без пробелов: 150 000 символов
  обрабатываются ≈ 30 с (sec_12 подвесит обработку до запуска песочницы).
- В `docker-compose.yml` нет отдельного сервиса-песочницы и ограничений; `SANDBOX_*`
  передаются в backend только через `.env`.
