# Проверка безопасности запуска кода (Т6)

Проверено: `main` @ `8e99270` (29.10.2026). Набор атак: `testdata/security/` (14 файлов),
прогон через API: `tests/security/run_security_suite.py`.

**Статус:** песочница реализована (`backend/app/analysis/sandbox.py`), но в `docker compose`
она не работает. Прогон атак в контейнере ещё не сделан: в среде проверки нет Docker. Ниже
разбор кода и проверка двух обходов, которые от Docker не зависят. Прогон в контейнере —
следующий шаг (см. «Как перепроверить»).

## Настройки контейнера (`sandbox.py`)

| Требование | Как сделано | Ок? |
|---|---|---|
| Без сети | `--network none` | ✅ |
| Лимит времени | `timeout 5` внутри + 15 с на хосте, затем `docker kill` | ✅ |
| Лимит памяти | `--memory 128m --memory-swap 128m` | ✅ |
| Лимит процессов | `--pids-limit 64` | ✅ |
| CPU | `--cpus 1` | ✅ |
| Файловая система | `--read-only`, `/tmp` — tmpfs 16 МБ `noexec,nosuid` | ✅ |
| Привилегии | `--cap-drop ALL`, `no-new-privileges`, пользователь `65534` | ✅ |
| Вывод | обрезается до 2000 символов | ✅ |
| Секреты backend | в контейнер не передаются, монтируется только папка с `main.py` | ✅ |

| Проверка через `==` | тесты сценариев сравнивают `==` | ❌ обход (sec_14) |

## Список проблем для Юры

| # | Проблема | Серьёзность | Предложение | Перепроверено |
|---|---|---|---|---|
| 1 | В `docker compose` песочница не работает: нет Docker CLI в образе backend и сокета; по умолчанию `SANDBOX_ENABLED=0`. В демо код кандидата не запускается, «правильность» не проверяется тестами | high | для демо: отдельный сервис-раннер или явный пункт в README и презентации «запуск кода выключен» | |
| 2 | Обход через маркер: код кандидата читает свой файл, печатает маркер, `os._exit(0)` | high | маркер не класть в файл: передавать через переменную окружения или запускать тесты отдельным файлом, который импортирует решение, и считать успех по коду выхода тестового файла | |
| 3 | Обход через `__eq__` | medium | в тестах сценариев проверять тип: `assert type(r) is Decimal and r == ...` | |
| 4 | `anonymize()` за квадратичное время + нет лимита длины `code`/`answers` в API | **critical** | `Field(max_length=20000)` в `Submission` (как `MAX_CODE_CHARS` анализатора) + исправить регулярку e-mail (Ангелина) | |

## Как перепроверить

```bash
cp .env.example .env            # в .env: SANDBOX_ENABLED=1, если песочница подключена
docker compose up -d --build
python tests/security/run_security_suite.py --api http://localhost:8000 --scenario 1
```

Результаты пишутся в `docs/qa/security-run.json`; перенести в таблицу выше, колонку «Ок?»
заменить на фактическое.
