# Проверка безопасности запуска кода (Т6)

Обновлено 31.10.2026 по `main` @ `2b98440`. Набор атак: `testdata/security/` (14 файлов).

## Итог

- Песочница переделана после первого разбора: решение и проверки запускаются отдельно
  (`runner.py` импортирует `solution.py`), результаты сравниваются **на стороне backend**,
  маркера успеха в файле больше нет. Оба найденных обхода (№13, №14) закрыты — перепроверено.
- В API ограничена длина: код ≤ 20 000 символов, ответ ≤ 5 000, ответов ≤ 10. Самое длинное
  допустимое решение обезличивается за 0,3 с (было: 300 000 символов — 124 с).
- В `docker compose` запуск кода выключен (`SANDBOX_ENABLED=0`) осознанно: backend не получает
  доступ к сокету Docker. Это написано в README и должно быть сказано на защите.
