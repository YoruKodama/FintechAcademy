## [critical] anonymize(): квадратичное время на длинной строке (риск подвесить сервер)
**Шаги:** `anonymize("a" * 50_000)`; затем 150 000 символов.
**Ожидал:** миллисекунды.
**Получилось:** 3,8 с и 30 с. Причина — `_EMAIL` начинает `[A-Za-z0-9._%+\-]+` с каждой позиции и доходит до конца строки, если нет `@`. Кандидат может прислать длинный литерал.
**Предложение:** якорь `(?<![A-Za-z0-9._%+\-])` перед локальной частью или предварительный поиск `@`; плюс лимит длины решения в API. Тест: `test_long_token_is_fast` (xfail).

## [medium] Карта без пробелов перед точкой не маскируется
`anonymize("Оплата с карты 4111111111111111.")` — номер остаётся. Причина: `_CARD_PLAIN` запрещает `.` после номера `(?![\w.])`. Карта с запятой или с пробелами маскируется. Тест: `test_plain_card_at_end_of_sentence_is_masked` (xfail).

## №16 [high] Monaco загружается с CDN: без интернета редактора нет
**Что сделал:** посмотрел `frontend/src/main.tsx`, `screens/ScenarioScreen.tsx`, `package.json`.
**Ожидал:** редактор работает без интернета (требование жюри: всё локально).
**Получилось:** `@monaco-editor/react` без `loader.config({ monaco })` берёт редактор с

**Предложение:** `import * as monaco from "monaco-editor"; loader.config({ monaco });` в `main.tsx`
(+ `monaco-editor` в зависимости). Проверка: открыть экран задачи с отключённым интернетом.

## №17 [high] Тесты задачи обходятся печатью маркера из своего файла

## №20 [medium] DEEP_NESTING: цепочка if/elif считается вложенностью
**Шаги:**
```python
def kind(x):
    for i in x:
        if i == 1: return 'a'
        elif i == 2: return 'b'
        elif i == 3: return 'c'
        elif i == 4: return 'd'
    return 'z'
```
**Ожидал:** нет `DEEP_NESTING` (глубина 2).
**Получилось:** «Вложенность 5 уровня». `elif` — это `If` в `orelse`, `_deepest` увеличивает глубину.
Ложное замечание у эталонных решений `s3_01_excellent`, `s3_02_good`.
**Предложение:** не увеличивать глубину для `If`, который единственный элемент `orelse` родительского `If`.
Тест: `backend/tests/testdata/test_testdata_analyzer.py::test_no_unexpected_findings[s3_01_excellent.py]` (xfail).
