# Материалы для жюри

AI-тренажёр собеседований для сотрудников банка (трек «Финтех без границ», ВТБ). Человек получает задачу на Python из банковской области, пишет решение в редакторе и отвечает на 2-3 вопроса. Система находит замечания в коде, локальная модель пишет разбор по-русски и ставит баллы 0-100.

## Как читать числа

- Число со ссылкой на источник: проверено по источнику.
- Число с пометкой **«оценка команды»**: источника нет, дан расчёт, допущения можно поменять.

## Что в проекте реально работает на дату сдачи

Работает: API, база сценариев, анализ кода по 8 правилам, экраны сценария, результата и панели руководителя, обезличивание текста перед моделью, локальная модель через Ollama (адаптер) и адаптер GigaChat как замена на российскую.

Работает с оговоркой: запуск кода кандидата в изолированном контейнере (без сети, 5 секунд, 128 МБ, не от root) включается переменной `SANDBOX_ENABLED=1` и требует Docker на сервере. Если Docker недоступен, код не запускается вообще.

Все данные в репозитории выдуманные.
