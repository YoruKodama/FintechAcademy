# Гайд: как записать видео-демо (Windows 11)

Цель: ролик 2-3 минуты, где виден весь сценарий на работающей системе. Раскадровка и реплики: [video_script.md](video_script.md).
Проверено на этой машине: стек из `docker compose` поднимается и использует вашу локальную Ollama.

## 1. Подготовка системы (10-15 минут)

1. Docker Desktop должен быть запущен (значок кита в трее, статус «Engine running»).
2. Ollama должна работать (значок в трее) и иметь модель: `ollama list` показывает `qwen2.5:7b`.
3. В корне репозитория создайте `.env`: `copy .env.example .env`, затем в `.env` поставьте три строки, чтобы backend
   использовал вашу Ollama на хосте, а не качал модель в контейнер:
   ```
   LLM_PROVIDER=ollama
   OLLAMA_URL=http://host.docker.internal:11434
   OLLAMA_MODEL=qwen2.5:7b
   ```
4. Запуск: `docker compose up -d --build`. Первая сборка занимает несколько минут. Проверка: http://localhost:8000/health
   отвечает `{"status":"ok"}`, http://localhost:3000 открывает приложение.
   (Раньше сборка падала, если Ollama на хосте уже запущена: порт 11434 был занят. Это исправлено в PR #12; если PR ещё не
   слит, закройте Ollama в трее перед запуском.)
5. **Прогрейте модель.** Первый запрос к модели после простоя идёт дольше минуты и может упереться в тайм-аут 60 секунд.
   Откройте приложение и один раз пройдите весь сценарий «вхолостую» (это же репетиция). Следующие запросы занимают
   около 30 секунд.
6. Очистите панель руководителя: репетиционные прохождения останутся в таблице. Самый простой способ: `docker compose down -v`
   и снова `docker compose up -d`, затем сразу сделайте один запрос к модели (прогрев), не заходя в приложение.

## 2. Чем записывать

### Вариант А (проще всего): Xbox Game Bar, встроен в Windows 11

Записывает окно браузера с микрофоном. Нам этого достаточно: весь сценарий идёт в браузере.

1. Откройте браузер на http://localhost:3000, сделайте окно во весь экран (F11 даёт чистый кадр).
2. Нажмите `Win + G`, в панели «Запись» нажмите кружок. Либо сразу `Win + Alt + R` (начать и остановить).
3. Микрофон: `Win + Alt + M` включает и выключает. Перед записью проверьте в панели Game Bar «Звук», что микрофон выбран и
   индикатор шевелится, когда вы говорите.
4. Готовые файлы: папка `Видео\Клипы` (Videos\Captures), формат MP4.

Ограничение: пишется только окно, в котором вы начали запись. Не переключайтесь на другие программы во время записи.

### Вариант Б: OBS Studio (бесплатно, больше управления)

1. Установите OBS Studio. Источник «Захват окна» выберите на окно браузера, «Захват входного аудиоустройства» на микрофон.
2. Настройки, Вывод: формат записи MP4, качество «Высокое». Настройки, Видео: 1920x1080, 30 кадров.
3. «Начать запись» и «Остановить запись».

## 3. Как держаться в кадре

- **Масштаб страницы** 110-125 % (Ctrl + плюс), чтобы текст читался на маленьком экране жюри.
- Закройте лишние вкладки и закладки, выключите уведомления (`Win + N`, режим «Не беспокоить»).
- Не показывайте `.env`, терминал с ключами, личные письма. Все данные в демо выдуманные.
- Код **вставляйте** (Ctrl + V), а не печатайте: редактор сам расставляет отступы и ломает набранный вручную код. Код лежит в
  `testdata/solutions/s1_03_float.py` (с ошибкой) и `s1_01_excellent.py` (хороший), ответы на вопросы в рядом лежащих `.json`.
- Говорите ровно и коротко, не читайте с листа слово в слово. Сценарий: [video_script.md](video_script.md).
- **Ожидание ответа модели (~30 секунд).** Либо говорите в это время («сейчас идёт обезличивание, анализ кода и разбор моделью,
  всё локально»), либо вырежьте паузу при монтаже.

## 4. Монтаж за 5 минут (по желанию)

Встроенный редактор Clipchamp (в меню «Пуск»). Импортируйте файл, перетащите на дорожку, подрежьте начало и конец,
паузу ожидания можно ускорить (скорость 2x или вырезать), экспорт 1080p. Если запись получилась сразу, монтаж не нужен.

## 5. Проверка перед отправкой

1. Посмотрите ролик целиком: звук слышно на всём протяжении, текст на экране читается, в кадре нет ключей и личных данных.
2. Длительность 2-3 минуты, размер до нескольких сотен МБ.
3. Загрузите на **Яндекс Диск** или Облако Mail (по условиям трека облако российское).
4. Включите доступ по ссылке («Поделиться», «Доступ по ссылке») и **откройте ссылку в окне инкогнито**, чтобы убедиться,
   что видео открывается без входа в аккаунт.
5. Вставьте ссылку в `docs/jury/sprint1_upload.md` (строка «Видео»).

## 6. Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| `docker compose up` пишет «port is already allocated» | закройте Ollama в трее и повторите, либо слейте PR #12 |
| Разбор долго не приходит | при первом запросе после простоя это нормально (до 1,5 минут); прогрейте модель заранее |
| В разборе написано, что ответ модели получить не удалось | модель не успела за 60 секунд; повторите отправку, она уже прогрета |
| Редактор не загружается | дождитесь загрузки страницы; редактор встроен в сборку и интернет не требует (после PR #5) |
| Нет звука | Game Bar, панель «Звук»: выберите микрофон; в Windows «Параметры, Звук, Ввод» проверьте уровень |
| Хотите показать без настоящей модели | поставьте `LLM_PROVIDER=stub` и скажите в видео, что это режим заглушки |
